# Вебсайт фонду підтримки постраждалих від війни

## Про проєкт

Сайт створений для представлення діяльності фонду, його місії,
контактної інформації та можливості підтримати роботу фонду.

## Функціонал

- Головна сторінка
- Інформація про фонд
- Опис діяльності фонду
- Інформація про підтримку та донати
- Контактна інформація
- Форма підписки на розсилку
